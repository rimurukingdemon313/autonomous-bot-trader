# radar-data

Written every hour by `.github/workflows/radar.yml` on `main`. **PAPER ONLY**: no key, no account, no order.

| File | What |
|---|---|
| `REPORT.md` | the current paper book, venue status, opportunities, forward-test status |
| `ledger.json` | every paper position (open and closed) and the hourly marks |
| `opportunities.json` | this hour's candidates passing the entry rule |
| `RADAR-1-look1.json` | the forward test's verdict, frozen once at day 60 (absent until then) |

Rules: `research/preregistrations/RADAR-1.md` on `main`. Plan: `docs/RADAR_PLAN.md`.
